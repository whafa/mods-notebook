Agent Hallucination & Mistake Log

A running log of wrong assumptions / requirement mistakes Claude made during coding that we later discovered and had to go back and fix. “Hallucination” here is used loosely (per whafa): any incorrect assumption about the data, the spec, the runtime, or existing state that shipped into work and cost us a correction.

  • Started: 2026-05-31, reconstructed from ~/.claude/.../memory/*.md + git log.
  • Ordering: most-recent first within each category.
  • Confidence: ✅ = documented in a memory file as my mistake (high confidence) · 🔍 = inferred from a fix(...) commit, root cause not yet confirmed to be mine (triage).
  • Maintenance: add new rows as they happen. Keep entries tight: Assumed → Actually → Cost → Fix.
  • Coverage gap: the MCP session-transcript search stayed gated (unsupervised mode), so the sweep was run manually via ripgrep over an internal agent path on 2026-05-31 — results in section E. That pass is noisy (much doc/memory text is injected into transcripts) so it is not exhaustive; the “To triage” list may still grow.

A. Domain / data-understanding hallucinations

(I misread what the data or the spec actually meant.)

A-2 — Quoted a lab-dish sentence as the FDA label, and inverted a drug interaction ✅ — 2026-08-07, found 2026-10-05

  • Assumed: encorafenib inhibits CYP3A4. disulfiram_due_diligence.md §5.5 quoted it as “a relatively potent reversible inhibitor of CYP3A4 and also a time-dependent inhibitor of CYP3A4” (FDA label). From that it warned that her BRAF inhibitor would blunt disulfiram’s CYP3A4-dependent activation, and with it the alcohol reaction.
  • Actually: in patients, encorafenib is a strong CYP3A4 inducer at steady state.
    • The evidence: with binimetinib, midazolam AUC fell 82% (Piscitelli et al., Clin Pharmacol Ther 2025, PMID 41215578). The FDA label says the same in §7.2 (at least since 10/2023), and so does the EU product information in §4.5.
    • What the quote really is: the in-vitro sentence of the EU product information (§5.2) and of the NCT03864042 protocol. No FDA label checked (2018, 2023, 2025) uses those words, and every source follows them with in-vitro induction.
    • How it got in: it reached the review through a WebSearch’s generated summary, which dropped those induction sentences. No label was opened, although the search had linked the 2018 and 2023 labels.
  • Cost: a safety warning that pointed the wrong way.
    • It was marked for the public notebook (2026-09-25), and the candidate catalog copied it unchecked (2026-10-01).
    • It never reached her prescriber, who received only the original article, and she has not started disulfiram.
    • It was found while building the Metro Map’s safety badge (#595).
  • Then a smaller repeat. My 2026-10-05 correction said the quote “came from an older label”. That was also unchecked, and also wrong. It reached a doc, an issue, a vector note and the MapleLog before Richard asked whether the inversion was ours or the sources’.
  • Fix: every copy carries a dated correction (PR #831). The true provenance and the independent sources are recorded (PR #843, #830).
  • Lesson:
    • A search summary is generated text, not a source. Quote and attribute only a document you opened, and name its version.
    • An in-vitro CYP profile never settles a clinical direction; the label’s §7 and the clinical DDI study do.
    • Check a correction’s own provenance before writing it down.
  • Source: session transcripts (the review’s session, 2026-08-07 04:53–05:00 PDT, and the Metro session, 2026-10-05/06); #830.

D. Process / execution slips (incl. source control)

(not assumption-hallucinations, but mistakes during coding we had to undo — logged for completeness)

Root cause of the git ones (D1, D2, D10): this checkout has a shared index + working tree + HEAD across parallel sessions. The user routinely has uncommitted WIP staged in that shared index, and another session can move HEAD out from under a command mid-run. Standing guardrails: commit with an explicit pathspec only (never bare git commit / -a); never git checkout/restore a file that may hold the user’s unstaged work; prefer gh pr merge (origin-side) over local git merge; re-check git branch --show-current before any local merge/commit.
