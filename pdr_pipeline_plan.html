KG choice — current production decision

  • PrimeKG is the production graph. 7,957 drugs, 30 relation types, rich drug-disease evidence. All Phase 9+ personalization targets PrimeKG.
  • GP-KG is paper-comparator only. 1,430 drugs, 9 relations. Sufficient to reproduce KG-Predict, insufficient for CRC personalization (only 1 of 5 RGCC high-sensitivity drugs is in GP-KG).
  • PrimeKG canonical checkpoint: Run B (primekg_corr_1l_400d_v1). Phase 7.5 Tier 1 ρ = +0.351, p = 0.00018 (n=109) — ⚠ superseded pending restatement, GH #324: the label was the mean of her two RGCC draws, which flattened the 12 drugs that inverted by class. Do not use as a baseline until re-run per timepoint.

See docs/PDR_NOTES.md for the full decision history and rationale.

Reproducibility & ent2id discipline (the gotchas you will hit)

  • Train + infer in the same Colab session. ent2id map is built from train.txt traversal order; reloading a checkpoint in a new session scrambles predictions.
  • GP-KG drug IDs: add 100M offset before PubChem lookup. IDs ≤0 after subtraction are non-drug entities (e.g. CIDEA gene).
  • PrimeKG drug-disease relations: three types — indication, off-label use, contraindication. Enumerate all three at inference time. (GP-KG uses treat.)
  • test.py flags: always pass -gcn_layer and -opn matching the checkpoint. Silent prediction scrambling otherwise.

Working conventions

  • New tasks: open a GitHub issue (CLAUDE.md, “Issue tracking”). If it blocks the current end-to-end run, label it critical-path + p0. (Deprecated 2026-09-28: adding to pdr_pipeline_task via the Pipeline tab or POST /api/mods/research/pipeline/tasks.)
  • New decisions: pdr_note_save(scope='global', kind='decision', pinned=true, ...).
  • New run findings: pdr_note_save(scope='run', scope_id='<uuid>', kind='insight', ...).
  • Run naming: {kg}_{opn}_{gcn_layer}l_{gcn_dim}d_v{n} (e.g., gpkg_corr_2l_200d_v1). The Tag taxonomy at mods_research_run.tags uses kg:<name>, opn:<name>, layers:N, dim:N, phase:<phase>, plus free-form labels (canonical, historical, etc.).
