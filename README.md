# MODS Notebook

Built output for **https://whafa.github.io/mods-notebook**.

Generated static files only. This is a deploy target, not a source repository —
nothing here is edited by hand, and every commit is a full rebuild.

The source markdown lives in a private repository. Publication is opt-in per
document and gated: a page ships only if its frontmatter says so, an independent
scanner reads the content rather than trusting that frontmatter, and the built
artifact is scanned again — visible text *and* link targets — before it is pushed
here. Some passages are deliberately generalised on the way out; inherited
genetic findings are not one person's data to publish.

**This repository's contents are the complete public surface.** What is here is
what is live; the diff of each commit is what changed.
